Painel do convite 💌

Só pra você. Não tem link na página dela; guarde esse endereço (/painel/) só pra você.

1) Ver o que ela escolheu

Cada clique dela num passeio é registrado automaticamente no Netlify.

  1. Abra o seu site no app.netlify.com
  2. Menu Forms → formulário escolha
  3. Cada envio mostra a opção escolhida, a mensagem e o horário.
  4. Para receber aviso por e-mail: Forms → Form notifications → Add notification → Email.

Na primeira publicação, confira em Site configuration → Forms se a detecção de formulários está ativada.

2) Editar textos e número

Mude o que quiser, teste os links e baixe o novo config.js. Depois é só substituir o arquivo na pasta, subir no GitHub e o Netlify publica sozinho.
